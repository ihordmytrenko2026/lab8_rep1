# Потік монет Лабораторна робота 9

Адаптивна форма зворотного зв’язку інтегрована в лендинг ЛР8: `index.html#feedback`.
Тематика: навчальне планування особистого бюджету у гривні.

## Запуск

Відкрити папку через Live Server або локальний HTTP-сервер. Готовий `css/tailwind.css` уже зібрано: сайт не потребує CDN Tailwind або встановлення пакетів для перегляду.

Для повторної збірки: `npm install`, потім `npm run build`. Tailwind CSS 3.4.17.
Для 36 перевірок бізнес-правил: `npm test` (Node.js, сторонні тестові пакети не потрібні).

## Файли форми

- `index.html`: семантичні поля, пояснення, згода, політика, нативний dialog.
- `assets/css/styles.css`: доповнення станів, backdrop, фокус і зменшення руху.
- `assets/js/validation.js`: п’ять функцій перевірки, UI-стани, input/blur/submit, скидання та модальне вікно.
- `tests/validation.test.cjs`: позитивні, негативні та граничні випадки.
- `vercel.json`: статичний деплой, без збірки на сервері.

Ім’я: 2–80 символів; повідомлення: 10–2000, після trim та підрахунку Unicode-кодових точок. Email: навчальна ASCII-маска, не перевірка існування скриньки. Телефон: строго `+380` і 9 цифр; пробіли, дужки, дефіси й локальний формат відхиляються. Автоматичного виправлення номера немає.

Зелена рамка — валідне поле, червона рамка та текст — помилка; помилки з’являються після blur або submit, виправлення оновлюються на input. Після успіху поля очищуються, відкривається модальне вікно. Tab/Shift+Tab залишають фокус у ньому; Escape, кнопка та клік поза карткою закривають його; фокус повертається до «Надіслати».

## Межі демонстрації

Форма не має бекенду: немає fetch, збереження, листів або реального надсилання. Не вводьте приватні відомості. Зовнішні відео, карта та інформер попереднього лендингу можуть звертатися до своїх сервісів. Для реального приймання звернень потрібні API та серверна валідація.
